how to cite ggplot2 in r

If you're citing ggplot2 in an R paper, thesis, or report, the easiest way is to let R generate the official citation:

citation("ggplot2")

This will give you the recommended citation, including the authors, year, title, and publication information for the version you have installed.

For example, a typical citation is:

Wickham, H. (2016). ggplot2: Elegant Graphics for Data Analysis. Springer-Verlag New York.

In BibTeX format, you can also use:

toBibtex(citation("ggplot2"))
In your text

You could write:

Data visualization was performed using the ggplot2 package (Wickham, 2016).

And in your references:

Wickham, H. (2016). ggplot2: Elegant Graphics for Data Analysis. Springer-Verlag New York.

Important: citation("ggplot2") is preferable because it reflects the citation information for the version installed in your R environment.

how to write to a csv in a different folder in R

Use write.csv() and give it the full path to the folder where you want the CSV saved.

Example
write.csv(my_data, "C:/Users/YourName/Documents/my_folder/my_data.csv",
          row.names = FALSE)

On Windows, you can also use forward slashes / even though Windows normally uses \.

If the folder is relative to your current working directory
write.csv(my_data, "data/output/my_data.csv",
          row.names = FALSE)

First check your current working directory with:

getwd()

And change it with:

setwd("C:/Users/YourName/Documents/my_project")
A cleaner approach with file.path()

This is especially useful if you're constructing paths programmatically:

folder <- "C:/Users/YourName/Documents/my_folder"

write.csv(my_data,
          file.path(folder, "my_data.csv"),
          row.names = FALSE)

If you're using RStudio, another convenient option is the here package, which avoids hard-coding your absolute Windows/Mac path:

library(here)

write.csv(my_data,
          here("data", "output", "my_data.csv"),
          row.names = FALSE)

in csv I have date data in this form "2026-08-22T10:45:00" is there any way for me to agregate the totals by month and year  

Yes. In R, the easiest approach is to convert that column to a proper datetime, extract the year-month, and then use group_by() + summarise().

Suppose your CSV looks like this:

date,value
2026-08-22T10:45:00,100
2026-08-25T14:30:00,50
2026-09-03T09:15:00,75
Using dplyr and lubridate
library(dplyr)
library(lubridate)

monthly_totals <- my_data %>%
  mutate(
    date = ymd_hms(date),
    month = floor_date(date, "month")
  ) %>%
  group_by(month) %>%
  summarise(
    total = sum(value, na.rm = TRUE)
  )

You would get something like:

month       total
2026-08     150
2026-09      75
If you want separate year and month columns
monthly_totals <- my_data %>%
  mutate(
    date = ymd_hms(date),
    year = year(date),
    month = month(date)
  ) %>%
  group_by(year, month) %>%
  summarise(
    total = sum(value, na.rm = TRUE),
    .groups = "drop"
  )

Result:

year   month   total
2026     8      150
2026     9       75
If you want to aggregate counts rather than sum a column

For example, if each row represents one transaction/event and you simply want to count how many occurred each month:

monthly_totals <- my_data %>%
  mutate(
    date = ymd_hms(date),
    month = floor_date(date, "month")
  ) %>%
  count(month)

You're right to question it. The function is comma(), singular, but depending on your installed scales version, it may not be available as expected.

The most reliable approach is to use label_comma():

scale_y_continuous(
  labels = scales::label_comma()
)

So your plot becomes:

ggplot(df, aes(x = Date, y = Sales_Count)) +
  geom_col() +
  scale_x_date(
    date_breaks = "2 months",
    date_labels = "%b %Y"
  ) +
  scale_y_continuous(
    labels = scales::label_comma()
  ) +
  labs(
    x = "Date",
    y = "Sales Count"
  ) +
  theme_minimal()
Why the confusion?
scales::comma → older/common scales API
scales::label_comma() → current recommended labelling function

So I'd use scales::label_comma() for your Quarto project.

how to get pdf from qmd file

If you're using Quarto with R, there are a few easy ways to turn your .qmd into a PDF.

1. From RStudio

Open your .qmd file, then click:

Render → Render PDF

Quarto will create a .pdf file in the same folder as your .qmd by default.

2. From the RStudio Terminal

In the folder containing your .qmd:

quarto render your_file.qmd --to pdf

For example:

quarto render ferry_report.qmd --to pdf
3. Set PDF as the default output

At the top of your .qmd:

---
title: "Toronto Islands Ferry Analysis"
format: pdf
---

Then you can simply click Render, and Quarto will produce the PDF.

If you get a LaTeX error

PDF generation usually requires a LaTeX installation. The easiest option is to install TinyTeX from R:

install.packages("tinytex")
tinytex::install_tinytex()

Then restart RStudio and try Render → Render PDF again.
